answer: 파이썬에서 리스트(list)와 튜플(tuple)의 주요 차이는 다음과 같습니다:

1. 변경 가능성 (Mutability)
   - 리스트는 변경 가능(mutable)합니다. 즉, 생성 후에 요소를 추가, 삭제, 변경할 수 있습니다.
   - 튜플은 변경 불가능(immutable)합니다. 생성 후에는 요소를 변경할 수 없습니다.

2. 문법
   - 리스트는 대괄호 [ ]를 사용하여 만듭니다. 예: [1, 2, 3]
   - 튜플은 소괄호 ( )를 사용하여 만듭니다. 예: (1, 2, 3)

3. 용도
   - 리스트는 요소를 자주 변경하거나 추가, 삭제할 때 사용합니다.
   - 튜플은 변경되지 않는 고정된 데이터 집합을 표현할 때 사용하며, 해시 가능하기 때문에 딕셔너리의 키로도 사용할 수 있습니다.

4. 성능
   - 튜플이 리스트보다 약간 더 빠르고 메모리를 적게 사용합니다.
